# LIGHT vs SHADOW — Prism Defense

An offline landscape lane-defense game for Android and iOS, built on Flutter +
Flame. You place light tools on a 21-tile grid; mirrors bend the beam, prisms
split it, and shadows walk the lanes trying to eat your tools.

No backend, no account, no network at runtime — the whole game runs in airplane
mode apart from the optional ad and IAP calls.

> This repository was originally a Plants-vs-Zombies Flutter widget demo. It has
> been repurposed; the old widget game is gone. Design history for the original
> lives in the git history before `ae7a5b6`.

## Verification

The canonical commands, and when each is required, live in [`AGENTS.md`](./AGENTS.md) §6.
The short version:

```bash
dart format lib test
flutter analyze     # must print "No issues found!"
flutter test        # must be all-green
```

## Getting started

```bash
flutter pub get
flutter run          # landscape-locked; a phone or emulator, not web
```

Levels in `assets/levels/*.json` are generated by `tool/gen_levels.py` with a
fixed seed — never hand-edit them.
